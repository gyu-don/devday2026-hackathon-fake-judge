# 制作チームのタスク計画

ボードに新規タスクが来たら、担当者が読める資料だけから計画案を作る設計です。対象は数名の制作チーム。資料探しと重複タスクの整理を減らします。生成案は担当者が確認してから使います。時間削減は未測定。

DevDayのMCP events for plugin automationsの体験を応用しています。MCP購読・外部サービス接続は未実装で、イベントはローカルから渡すモックです。`entrypoints.json`は提出物のローカル経路一覧です。

CLIはデモデータで計画案を表示します。空の資料では再入力を促します。別のイベント入口は権限内の資料を選び、イベントIDの重複を抑止します。導入には業務の資料形式・権限設定を合わせる作業が必要です。
